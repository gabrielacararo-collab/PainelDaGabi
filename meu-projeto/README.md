Painel de Ideias

Aplicação em React para anotar ideias de projeto e não perdê-las.

Funcionalidades

- Adicionar ideias (não aceita campo vazio)
- Marcar ideias como concluídas
- Remover ideias
- Contador de ideias e de concluídas

Usado

React (useState)
-SS

Como rodar

bash
npm install
npm run dev


Depois, abra o endereço mostrado no terminal (geralmente `http://localhost:5173`).

As ideias ficam só na memória e são perdidas ao recarregar a página.
